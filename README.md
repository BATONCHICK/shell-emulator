# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Группа: ИКБО-22-25  
Вариант: 20

## Описание

Эмулятор командной оболочки UNIX-подобной ОС.

## Реализовано

### Этап 1

- интерактивный режим REPL;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- раскрытие переменных окружения;
- обработка неизвестных команд.

### Этап 2

- параметры командной строки `--vfs` и `--script`;
- отладочный вывод параметров;
- выполнение команд из стартового скрипта;
- остановка скрипта при первой ошибке;
- выполнение `exit` из стартового скрипта.

## Запуск

```bash
./run.sh --vfs ./test_vfs --script ./start.txt
```

Windows:

```bat
run.bat --vfs .\test_vfs --script .\start.txt
```

## Пример

```text
VFS: ./test_vfs
Script: ./start.txt
VFS:/$ ls
ls []
VFS:/$ cd /home
cd ['/home']
VFS:/$ ls /test
ls ['/test']
VFS:/$
```
