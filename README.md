# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Группа: ИКБО-22-25  
Вариант: 20

## Описание

Эмулятор командной оболочки UNIX-подобной ОС.

На этапе 1 реализован интерактивный режим REPL.

## Реализовано

- приглашение к вводу с именем VFS;
- разбор команды и аргументов;
- раскрытие переменных окружения, например `$HOME`;
- команда `exit`;
- команды-заглушки `ls` и `cd`;
- обработка неизвестных команд.

## Запуск

Windows:

```bat
python src\main.py
```

## Пример работы

```text
VFS:/$ ls
ls []

VFS:/$ cd /home
cd ['/home']

VFS:/$ cd $HOME
cd ['/Users/user']

VFS:/$ hello
Неизвестная команда hello

VFS:/$ exit
```
